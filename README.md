# Triple Double Real Estate - Modern Institutional Website Concept

An original, high-fidelity corporate homepage concept designed for **Triple Double Real Estate** (a premier real estate investment, operations, and management firm).

Inspired by top-tier real estate developer sites (*Crescent Heights* & *Related Group*), this project delivers an authoritative institutional presence with refined serif typography, structured visual hierarchy, interactive portfolio showcase, and desktop/tablet/mobile responsive layout.

---

## 🌟 Key Features

- **Header & Navigation**: Glassmorphism navbar with brand emblem logo, main links, and Investor Portal CTA.
- **High-Impact Hero**: Bold headline copy, architectural imagery, and dual action CTAs.
- **Key Track Record Banner**: Real-estate performance metrics ($1.8B+ Volume, 12.5M+ Sq. Ft. Managed).
- **Core Operating Platforms**: Dedicated divisions for *Real Estate Investment*, *Leasing & Advisory*, and *Asset Management*.
- **Interactive Portfolio Gallery**: Filterable property grid (Commercial, Luxury Residential, Mixed-Use).
- **Executive Leadership**: Professional executive board profile cards.
- **Interactive Viewport Switcher**: Embedded preview bar to toggle between Desktop, Tablet (768px), and Mobile (390px) views.
- **Contest Submission Toolkit**: Built-in modal displaying color codes, font hierarchy, and design rationale.

---

## 🎨 Design Specifications

- **Color Palette**:
  - Primary Navy: `#0B192C`
  - Accent Gold: `#C5A880`
  - Obsidian Dark: `#070F1B`
  - Text Light: `#F9F8F6`
- **Typography System**:
  - Primary Serif Heading: `Cormorant Garamond`
  - Body & UI Sans-Serif: `Plus Jakarta Sans`
